# Dog Adoption Platform

## Description

This project aims to create Europes first centralized webpage and database with all european shelter dogs. The aim is to create a simple tool for people in all Europe to use for finding the perfect dog for them and to promote adoption instead of buying a dog. Once the webpage is up and running effectively then we hope to offer more different services to Europes dog community.

## Features

* Search and browse available dogs in all Europe
* Filter by sex, age, size, country, breed, id number.
* Get information about the dog and photos
* Get shelters contact details
* Get general info from the upper menue
* Donate
* Share happy dog stories in our blog
